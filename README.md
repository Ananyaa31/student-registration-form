# Student Registration Form

A beginner friendly registration form project built with HTML, CSS, and JavaScript.

## Features

- Student name, email, mobile, course, gender, and password fields
- Checks the email format and 10 digit mobile number
- Checks password length and password confirmation
- Shows an error beside fields that need attention
- Shows a success message when the form is valid
- Responsive layout for mobile screens

## Project files

- `index.html` contains the form fields and page structure.
- `style.css` contains the colors, spacing, and responsive layout.
- `script.js` validates the form and displays messages.

## Run it

Open `index.html` in a web browser. No installation is needed.

## Note

This is a frontend learning demo. It does not send registration information to a server or save it in a database.
